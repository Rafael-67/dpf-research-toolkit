# Security policy

## Supported version

Only the latest release candidate is supported during the local pilot.

## Reporting

Do not disclose a suspected vulnerability in a public issue. Contact the project maintainers privately; a repository-specific reporting address must be added before public release.

Include the affected version, reproduction steps, impact, and any suggested mitigation. Do not include real study data or personal information.

## Data boundary

This static prototype stores data in the browser and exports files only after a user action. It has no telemetry or application backend. It is not approved for real studies without institutional data-protection and security review.
